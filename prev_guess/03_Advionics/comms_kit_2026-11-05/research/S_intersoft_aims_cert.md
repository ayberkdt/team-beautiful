## What the page says [D-ag]
- **What is offered:** IFF "platform certification" test equipment and engineering. The aim is to meet "NATO IFF Test Requirements" or the equivalent from the "U.S. DoD AIMS Program Office".
- **Standards named:**
  - AIMS (US DoD) sets Mode 5 requirements: cryptographic integrity, message formats and system behaviour.
  - **NATO AEtP 12** sets the procedures for testing and validation in joint environments.
- **Test tools:** Mode S and Mode 5 testing is done with RES®, which provides a "controlled, repeatable test environment". This validates both transponder and interrogator performance. Platform upgrades to Mode 5 are also covered.
- **Services:**
  - Pre-certification consulting: test plans and flight patterns.
  - On-site data acquisition.
  - Signal analysis and documentation.
  - Coordination with NATO nations.
- **Gaps:** no numbers and no customers on the page.
