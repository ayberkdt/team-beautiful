# 00_Common — rules, formatting and notes shared by all four challenges

| Folder | What |
|---|---|
| `rules_and_templates/` | `EUROAVIA Ideathon 2026.pdf`, `Ideathon-2026-Regulations-1.1.pdf`; `originals_2026-11-05/` = the organisers' `Rules and Criteria.xlsx`, report template (`Ideathon_Template_2026.docx`) and deck template (`.pptx`), with `SHA256SUMS.txt` |
| `organiser_notes/` | transcriptions of the handwritten task notes (4 Nov): one per challenge, a cross-challenge comparison, `Tum_Gorevler_Detayli.md` |
| `docs/` | `21_final_challenges_coordination.md` (parallel-work rules, temp folders on D:), `references.md` (bibliography generated by `scripts/build_references.py`) |

Scoring (from `Rules and Criteria.xlsx`, per challenge 100 points): report R1 problem & scoping 10, R2 approach &
methodology 20, R3 rigour & feasibility 15, R4 innovation 10, R5 value for the company 10, R6 structure/clarity/
compliance 10; talk P1 storytelling 8, P2 persuasiveness incl. Q&A 7, P3 visuals 5, P4 delivery & time 5. Report at
most 5 pages (references extra), talk 4:00 hard cut, −10 per started 5 min late.

Formatting: report = A4, margins 35 mm top/bottom and 17 mm sides, styles Heading1 / Heading2 / EATitle3 / Title4;
deck = 16:9 (20 × 11.25 in), cover slide (team name, short description) + content slide. Start each challenge's
report and deck from a copy of the templates in `originals_2026-11-05/` (Ansys copies: `01_Ansys/submission/`).
