# Üretilmiş 3B görseller

Hepsi seçilen tasarımla üretildi: `outputs/variants/short_demo/files_0p5kg/design.json`, v0.8, 38,23 kg, 0,5 kg uçuş kamerası. Kodu ve komutları: `../code/visual/README.md`.

| Klasör | İçerik |
|---|---|
| `parts/` | dokuz mekanizma, tek başına: pervane, göbek, tahrik, kol, gövde, iç donanım, güneş, yük, anten |
| `vehicle/` | birleşik araç: stüdyo, bulut ışığı, katlı hâl, etiketli |
| `films/` | 1920×1080 MP4: araç turu, bulutta tur, patlatma, ortam, yolculuk (toplam 107 s) |
| `storyboard/` | yolculuğun beş evresi, tek slayt |

Bulutların biçimi ve görüş mesafesi görsel seçimdir. Gerçekte bulut içinde görüş 2–3 km'dir. Bulut bantlarının yüksekliği tasarım dosyasındadır (Titov 2018). `scripts/export_github.py` MP4 dosyalarını açık depoya almaz.
